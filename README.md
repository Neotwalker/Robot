# Robot Cursor Hero — Abzalov Lab

Интерактивный hero-блок, собранный заново из видео `2026-09-18 00:35:07.MP4` из рабочей Google Drive-папки.

## Реализация

- Старые `robot-body.webp`, `robot-head.webp` и `sprite-v2` больше не используются.
- Из исходного MP4 отобраны 15 характерных ракурсов головы и собраны в WebP-atlas 5×3. Для GitHub atlas хранится в 6 текстовых base64-частях и собирается в браузере один раз при загрузке.
- Курсор относительно центра робота переводится в горизонтальное и вертикальное направление взгляда.
- Между соседними состояниями используется короткий crossfade, а координаты курсора сглаживаются через `requestAnimationFrame`.
- При уходе курсора робот плавно возвращается в нейтральное положение.
- На touch-устройствах положение меняется по касанию, затем возвращается в центр.
- Поддерживается `prefers-reduced-motion`.
