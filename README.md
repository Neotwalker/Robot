# Robot Cursor Hero — Abzalov Lab

Интерактивный hero-блок пересобран на основе нового исходного видео `2026-09-18 00:35:07.MP4` из рабочей папки Google Drive.

## Что изменилось

- Старые `robot-body.webp`, `robot-head.webp` и `assets/sprite-v2/*` удалены.
- Новый визуал не использует старого робота: 9 ракурсов извлечены непосредственно из нового 5-секундного видео и собраны в один WebP-atlas 3 × 3.
- Atlas хранится в `assets/video-frames/*.b64`: браузер один раз собирает из частей WebP и дальше переключает кадры локально без сетевых запросов на каждый поворот.
- На desktop положение курсора определяет направление взгляда/поворота; между кадрами используется короткий crossfade и инерция.
- На touch направление меняется по касанию, а без взаимодействия есть спокойный idle.
- Поддерживается `prefers-reduced-motion`.
- Чистые HTML / CSS / JavaScript, без зависимостей и сборщика.

## Локальный запуск

Из-за загрузки atlas-частей страницу нужно открывать через локальный HTTP-сервер:

```bash
python3 -m http.server 8080
```

Затем открыть `http://localhost:8080`.
